# Isla Viva: respaldo del proyecto Godot

Proyecto original conservado desde dungeon-sims, commit c6d6312c.

## Abrir

1. Extrae IslaViva-Godot.zip.
2. Importa legacy/godot/project.godot en Godot 4.7 o una version compatible.
3. Ejecuta la escena principal con F6/F5 segun corresponda (F5 ejecuta el proyecto).

El ZIP conserva scripts, escenas, recursos originales, configuraciones de importacion,
UID, pruebas, data/town.json, herramientas de conversion y licencias.
El ejecutable del motor Godot no estaba presente en el proyecto de origen.
Jugar-Godot.bat espera ese ejecutable en godot/Godot_v4.7.2-stable_win64.exe.
Puedes usar directamente tu instalacion de Godot para importar el proyecto.
README.md dentro del ZIP es la documentacion original y tambien menciona el port C++;
los archivos del port no forman parte de este respaldo de Godot.

## Verificacion del archivo

El SHA-256 se incluye en SHA256SUMS.txt. MANIFEST-SHA256.txt dentro del ZIP
registra el hash de cada archivo respaldado. No se incluyen caches .godot,
partidas personales ni archivos del repositorio Git.
